# Provider Member Portal
This is the backend API for the Provider and Member Web Access Portal built with ASP.NET Core Web API.

## Features
- HTTPS configuration with CORS enabled
- Swagger UI for API documentation
- Modular structure for maintainability

## Technologies Used
- ASP.NET Core Web API
- Entity Framework Core
- Swagger (Swashbuckle)
